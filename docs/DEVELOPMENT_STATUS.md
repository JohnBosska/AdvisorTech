## Известные проблемы и ограничения
- Connector Agent как приложение не существует: базы в закрытой сети не загрузить; серверные коннекторы требуют публичный адрес.
- MS SQL напрямую не поддерживается (нет драйвера в образе); 1С на MS SQL — через OData.
- Удаления в источнике не отслеживаются: инкремент по курсору видит только новые и изменённые записи.
- Смена `CONNECTOR_SECRET` делает сохранённые учётные данные нечитаемыми (ввести заново).
- Все расчёты BI идут в браузере по снимку до 5000 строк / 5 МБ.
- Страницы кабинета (дашборд, запасы, финансы, логистика…) — демо-данные.
- SMTP не настроен (регистрация без писем), DNS для `api.advisortech.ru` отсутствует.
- Эмбеддинги зависят от баланса cloud.ru; чат-модели cloud.ru отвечают 402.
- Anthropic недоступен из региона прода.
- Роли фиксированы (4), RLS/CLS отсутствуют. Аудит не покрывает вход/выход (события вне организации).

## Архитектурные решения
- Модульный монолит FastAPI; фоновые задачи — Temporal (воркер развёрнут).
- Векторы — pgvector (не Qdrant), решение владельца.
- LLM — GigaChat / DeepSeek через `get_llm`; ИИ никогда не считает числа и не пишет SQL напрямую.
- Внешние источники читаются только на чтение, пароли не хранятся; внутренние адреса запрещены.
- Сырой слой: `raw_records` (JSONB) с upsert по (организация, подключение, сущность, ключ); тенант в каждом запросе.
